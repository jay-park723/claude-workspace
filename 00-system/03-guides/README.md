# 03-guides — 기준 문서 (Source of Truth)

Claude에게 스킬·에이전트·CLAUDE.md를 만들게 할 때 **"이 문서 기준으로"** 짚어 주는 공식 가이드 요약본입니다.

| 파일 | 언제 짚나 |
|------|----------|
| `skills-guide.md` | 스킬 만들 때 — `@skills-guide.md 이 가이드 기준으로 스킬 만들어줘` |
| `subagents-guide.md` | 서브에이전트 만들 때 — `@subagents-guide.md 기준으로 에이전트 만들어줘` |
| `claude-md-guide.md` | CLAUDE.md 다듬을 때 — `@claude-md-guide.md 기준으로 내 CLAUDE.md 점검해줘` |

> Claude Code 공식 문서(code.claude.com/docs)를 정리한 것입니다. 기준 버전은 각 파일 상단 `Updated`에 있습니다. 소스도 낡습니다. 오래됐다 싶으면 "공식 문서 기준으로 최신인지 확인해줘"라고 하세요.
