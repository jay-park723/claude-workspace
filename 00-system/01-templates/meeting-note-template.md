## 작성 규칙

1. **순서 고정** — 일정 → 참석자 → 주요 안건·결론 → 추가 논의·액션 → 상세 기록(인용)
2. **검증된 것만 본문에.** STT 불명확·미확인 고유명사는 본문에 넣지 말고 작성자와 먼저 해결한다
3. **민감 내용은 🔒 표시 후 확인을 거쳐 반영.** 판단 기준:
   - 원가·마진·단가 등 수익 구조
   - 특정 개인·거래처의 평판이나 계약 상태
   - 회사 상황을 과도하게 부정적으로 읽히게 할 발언
   - 타사 내부 정보
   → 걸리면 별도 private 기록으로 분리하고 본 회의록에서는 뺀다
4. **참석자 실명 표기.** 화자 미확인 상태로 배포하지 않는다
5. **1인의 관측은 결론으로 쓰지 않는다** — 4.3 사실 확인 필요로 내린다
6. **원본 STT는 같은 폴더에 `_원본-STT_YYYY-MM-DD.txt`로 보관.** 수정하지 않는다
7. **회의 1건 = 폴더 1개** (`YYYY-MM-DD_주제/`)
